# Result-data policy

Files in this directory are public-safe exports containing case identifiers,
conditions, monitor scores, token counts, status, and aggregate analysis. Model
prose is intentionally removed because it can quote or paraphrase encrypted
benchmark transcripts. Provider error messages are removed because they can
contain request details.

Raw append-only API outputs belong under `private/`, which is ignored by Git.
Generate a public export with:

```bash
uv run origin-guard sanitize \
  --source results/private/pilot-raw.jsonl \
  --output results/pilot-public.jsonl
```

The paired analysis works on sanitized exports. Do not publish decrypted
SLEIGHT-Bench content, raw prompts, raw model reasoning, or benchmark canaries.

`pilot-margin-effects.svg` is the canonical dependency-free figure generated by
the repository script. `pilot-margin-effects.png` is a print-rendering derivative
used in the PDF research report.

File inventory:

- `pilot-opus46.jsonl` and `pilot-opus46-summary.json`: sanitized completed
  44-cell exploratory pilot and its deterministic analysis;
- `pilot-report.md`: human-readable interpretation with limitations; and
- `pilot-margin-effects.svg` / `.png`: generated exploratory figure.

No file currently contains results for `neutral_provenance` or `policy_only`.
Those conditions remain implemented, frozen, and unrun.
